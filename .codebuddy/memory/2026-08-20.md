## 环境坑：Windows 下 `bash` 指向 WSL

- PowerShell 里直接 `bash` 会走到 `C:\Users\...\WindowsApps\bash.exe`（WSL），报 `WSL_E_WSL_OPTIONAL_COMPONENT_REQUIRED`。
- 正确做法：用 Git Bash 完整路径 `& "C:\Program Files\Git\bin\bash.exe" build-module.sh`（PowerShell 调用 exe 需 `&` 操作符）。
- 打包脚本实际用 python3(zipfile) 打包，不依赖 `zip` 命令。
